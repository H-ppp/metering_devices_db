# metering_devices_db
Данный репозиторий содержит решение тестового задания от компании NEWLAND. 

В рамках поставленной задачи было необходимо: 
- разработать модель данных, описывающую жизненный цикл приборов учета и изменение их показателей;
- разработать функцию, которая на основании входных параметров: место размещения, отчетный период - рассчитывает перечень приборов учета и их показания

Подробное описание модели данных приведено в документе [data_model](docs/data_model.md).
Процесс тестирования и полученные результаты описаны в документе [testing_report](docs/testing_report.md).
Инструкция по развертыванию приведена в [deployment_guide](docs/deployment_guide.md).
