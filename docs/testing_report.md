### Анализ производительности

Чтобы убедиться, что модель рассчитана на нагрузку хранения и обработки более 100 млн записей, следует выполнить следующий запрос: 


```sql
EXPLAIN (ANALYZE, BUFFERS, FORMAT TEXT)
SELECT * FROM get_monthly_meter_report(
    (SELECT location_id FROM locations WHERE address = 'г. Фаниполь, ул. Зеленая, д. 83'), 
    '2026-01-01'
);

````

Здесь показатель Partition Pruning укажет, что планировщик исключил все партиции, кроме readings_2026_01 (строки вроде Subplans Removed: 6 или явное указание только одной партиции).
Index Scan или Index Only Scan проиллюстрирует, что для подзапросов LATERAL используется индекс, а не последовательное чтение.
Buffers: shared hit=... показывает, что данные были взяты из кэша памяти, а не с диска, что критично для скорости.
