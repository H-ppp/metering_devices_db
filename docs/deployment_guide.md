# Инструкция по развертыванию

Данная инструкция описывает процесс развертывания модели базы данных и функции отчетности на сервере PostgreSQL.

### Системные требования

- установленный клиент Git;
- установленный PostgreSQL версии 13 или выше;
- утилита командной строки `psql` или любой графический клиент (DBeaver, pgAdmin);
- доступ к БД с правами на создание таблиц и функций


### Шаг 1: Клонирование репозитория

Сначала необходимо получить исходный код проекта на ваш локальный компьютер или сервер.


```bash
git clone <REPO_URL>
cd meter-readings-db
```


где REPO_URL - ссылка на репозиторий с проектом.

### Шаг 2: Создание базы данных (опционально)

Если база данных еще не создана, выполните следующие команды в терминале от имени пользователя `postgres` или суперпользователя:


```bash
# Создание базы данных
createdb meter_readings_db
```

### Шаг 3: Создание объектов базы данных

Выполните основной скрипт, который создаст типы данных, таблицы, индексы, партиции и функцию отчета.
Убедитесь, что вы находитесь в корневой директории склонированного репозитория, и выполните:


```bash
psql -U ваш_пользователь -d meter_readings_db -f metering_dev_ddl_function.sql
```


### Шаг 4: Загрузка тестовых данных

Чтобы убедиться в работоспособности функции и проверить пограничные сценарии, выполните скрипт с тестовыми данными:


```bash
psql -U ваш_пользователь -d meter_readings_db -f test_data.sql
```

### Шаг 5: Проверка работоспособности

Выполните тестовые запросы из документа [test_script.sql](test_script.sql) через psql или ваш SQL-клиент, чтобы убедиться, что функция возвращает корректные данные.
